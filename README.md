# ProofResearch

**공시 근거를 확인하며 글로벌 기업을 비교하는 AI Agent 프로젝트.**

기존 KIC 공모전 기획안을 구현하고 있습니다. 현재 **SEC 수집·원문 표 대조·Decimal 검산·기업/공시별 문단 검색·GPT-6 Luna 도구 호출 Agent**를 연결했습니다. 개발 20·동결 40문항 평가를 실행했으나 120회 중 40회가 API 잔액 오류로 실패해 비교 성능은 확정하지 않았습니다. 예선·본선 PDF, 발표 대본과 저장 실행 결과 해설 영상을 검토안으로 준비했습니다. 연결 성공이나 가상 예제를 측정된 정확도로 표현하지 않습니다.

## 바로 실행하기

Python 3.12와 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 사용합니다. 프로젝트 폴더에서 실행하세요.

```powershell
uv sync --frozen --extra dev
uv run streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다. **가상 예제 → 기업 선택 → 비교 보고서 만들기**로 키 없이 동작합니다.

- 예제 기업 A·B: 동일 기간 비교와 정상 계산.
- 예제 기업 A·C: 서로 다른 결산기간으로 기업 간 직접 비교 보류.
- 기준일을 과거로 변경: 당시 제출된 공시만 선택. 자료가 부족하면 보류.
- 보고서에서 HTML, CSV, 근거·실행 기록(JSON)을 다운로드할 수 있습니다.

예제 기업과 수치는 모두 합성 데이터입니다. 실존 기업명이나 실제 SEC 원문 링크를 붙이지 않습니다.

화면 없이 파일로 실행하려면:

```powershell
uv run proofresearch sample
uv run proofresearch sample --tickers SAMPLE_A SAMPLE_C --as-of 2026-03-01
```

`reports/<실행 ID>/`에 `report.html`, `comparison.csv`, `evidence.json`, `events.jsonl`이 생성됩니다.

## 실제 SEC 조회

SEC는 [공개 API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)를 제공합니다. 자동 접근에는 [식별 가능한 요청 헤더와 접근 정책](https://www.sec.gov/about/developer-resources)이 적용됩니다.

운영자 연락처가 정해지면 아래처럼 **로컬 환경변수에만** 설정하세요. 예시 이메일을 실제 연락처로 바꿔야 하며, 예시 그대로는 실행되지 않습니다.

```powershell
$env:SEC_USER_AGENT = 'ProofResearch 실제연락이메일'
uv run proofresearch sec --tickers AMD INTC NVDA --as-of 2026-10-11
# 같은 터미널에서 화면을 실행하면 'SEC 실제 공시' 모드를 사용할 수 있습니다.
uv run streamlit run app.py
```

또는 `.env.example`을 `.env`로 복사해 값을 채우고 `uv run --env-file .env streamlit run app.py`로 실행합니다. 연락처는 ASCII 영문 형식의 이메일을 사용합니다. `.env`는 Git 추적 대상에서 제외됩니다.

## AI 분석 실행

로컬 `.env`에 `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-6-luna`, `PROOFRESEARCH_MAX_COST_KRW`, `PROOFRESEARCH_TOTAL_BUDGET_KRW`를 설정합니다. 현재 사용자가 확정한 한도는 요청당 500원, 전체 실험 50,000원입니다. 화면의 **SEC 실제 공시 → 질의 입력 → AI 원문 검색·사업 위험 설명 포함 → 비교 보고서 만들기**로 실행합니다.

```powershell
uv run --env-file .env proofresearch sec --agent --tickers AMD INTC NVDA --as-of 2026-10-11
```

- 모델은 실행 계획·기업·기준일·지표를 정리하고 재무 수집/계산, 원문 검색, 보고서 종료 도구를 선택합니다. 검색 결과가 부족하면 이유를 기록하고 검색어를 바꿀 수 있습니다.
- 도구 12회, LLM 6회, 재탐색 합계 2회, 요청 전체 180초를 적용합니다. 작업은 별도 프로세스에서 실행해 멈춘 네트워크 호출도 시간 한도에 종료합니다. 결과 반환·프로세스 정리에는 짧은 추가 시간이 생길 수 있습니다.
- 계산값은 코드가 작성합니다. 모델의 정성 설명에는 검색된 같은 기업·공시의 인용 ID와 정확한 구절이 필요합니다. 구절 일치가 설명의 의미 타당성까지 증명하지는 않습니다.
- SQLite FTS5 키워드 검색을 사용합니다. 임베딩 검색은 사용하지 않습니다. 동결 평가의 실행 범위와 실패는 아래 평가 문서에 기록합니다. 수정본이 있는 원본의 정성 근거는 검토된 변경 범위에 따라 Risk Factors로 제한합니다.
- 비용은 `.cache/usage.sqlite3`에 원자적으로 예약합니다. 동시 요청과 재시작에서도 합산하며, 응답이 끊긴 호출은 최대 예약액을 유지합니다. 이 파일을 지우면 누적 한도가 초기화됩니다. 다른 프로젝트나 계정 전체의 지출은 통제하지 않습니다.
- [공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-6-luna)을 2026-10-11에 확인했습니다. 예산 예약은 캐시 쓰기·지역 할증을 포함한 상한과 **USD당 2,000원**의 내부 여유 환산을 사용합니다. 실제 환율·카드 청구액이 아니며, 토큰 사용량과 환산액을 별도로 기록합니다. 가격 기록은 30일 후 유료 호출을 막으므로 제출 전에 재검토해야 합니다.

**2026-10-12 실제 Agent 확인:** 세 기업 분석은 LLM 3회/도구 3회, 15.1초, 보수적 예산 환산 약 3.7원이었습니다. AMD·Intel 정상 비교와 의도적으로 검색어를 누락시킨 재탐색 시연도 실행했습니다. [시연 기록](docs/demos.md), [평가 항목별 근거](docs/contest-evidence.md)를 참고하세요. 자동 검사 89개 통과와 이 실행 기록은 독립 정확도 평가를 대체하지 않습니다.

**2026-10-11 실제 연결 확인:** AMD·Intel·NVIDIA의 제출 이력과 Company Facts, 총 6개 API 응답을 라이브로 수집했습니다. Intel·NVIDIA의 계산은 규칙을 통과했고, AMD의 최신 선택 10-K/A에는 필요한 표준 계정 값이 없어 해당 기간 지표 4개를 보류했습니다. 이는 연결·구조화 데이터 검사 결과이며, 10-K HTML 원문 대조나 독립적인 정확도 평가 완료를 뜻하지 않습니다. 운영자 연락처는 로컬 `.env`에만 보관합니다.

**원문 대조 단계:** 같은 날 10-K HTML 6개와 AMD 수정본 HTML 1개를 추가 확보했습니다. 원문 6개 보고기간의 매출·영업이익과 최신 공시의 전기 매출, 총 15개 고유 근거를 대조했고 이에 의존하는 21개 지표가 규칙을 통과했습니다. 재실행은 13개 캐시 스냅샷을 사용했으며 기업 간 비교는 기간·계정 차이로 HOLD였습니다. 77개 오프라인 회귀 검사가 통과했습니다. 이 결과는 동결 정답셋을 통한 독립 평가가 아닙니다.

실제 조회는 서버 측에서 실행하며, API 키는 필요하지 않습니다. CIK와 응답의 기업 식별자도 대조합니다.

## 현재 검증 규칙

- 대상: AMD·Intel·NVIDIA, 기업별 최근 **2개 보고기간**의 10-K 또는 기준일까지의 최신 10-K/A. 분기·부문별·사용자 정의 계정은 지원하지 않습니다.
- 제출일이 기준일 이후인 자료는 제외합니다. 일 단위 기준이며 장중 시점은 지원하지 않습니다.
- 제출 이력과 값의 accession number·제출일·서식·보고 종료일을 대조합니다. `fy`, `frame`만으로 연도를 판단하지 않습니다.
- 350~380일의 연간 USD 표준 계정만 선택합니다. 전환 회계연도는 보류할 수 있습니다.
- 동일 계정·공시·종료일에서 값 또는 시작일이 충돌하면 보류합니다.
- 매출과 영업이익의 기간·통화·공시가 일치할 때만 영업이익률을 계산합니다.
- 최근 2개 보고기간 각각에서 4개 지표를 검사합니다. 매출증가율은 해당 공시에 함께 보고된 당기·전기 매출로 계산합니다. 다른 공시의 수치와 자동으로 섞지 않습니다. 기간은 연속되어야 하며 길이 차이는 7일 이내입니다.
- 수정 공시에 필요한 값이 없으면 보류합니다. 다만 `amendments.json`에 원문 설명을 검토한 특정 수정본이 등록되어 있고 문서 해시가 그대로일 때만 같은 기간의 원본 재무 표를 사용합니다. 원본·수정본과 판단 사유를 함께 표시합니다. 현재 등록된 예외는 AMD 2025 회계연도의 고객 부문 ASP·판매량 증감률 정정 1건입니다. 새로운 수정본이나 변경된 문서는 자동 승인하지 않습니다.
- `Decimal` 정밀도 28자리로 계산하고, 화면만 소수 둘째 자리로 표시합니다. 원래 값과 식은 JSON에 남습니다.
- 기업 간 기간·통화·계정이 다르거나 필수 근거가 부족하면 직접 비교를 보류하며 순위를 만들지 않습니다. 기업별 값은 각 기간과 함께 열람할 수 있습니다.

**PASS는 자료와 계산 규칙을 통과했다는 뜻입니다.** SEC 모드는 보이는 원문 표의 iXBRL 값·USD 단위·기간·부호·배율을 Company Facts와 자동 대조합니다. 누락·충돌·해석 불가능한 형식은 관련 비율까지 보류합니다. 문서 SHA-256, 표·행·셀 번호, XPath, 요소 ID와 표시값을 보존합니다. 셀 번호는 병합 셀을 펼친 시각적 열 번호가 아닌 HTML 셀 순서입니다. 자동 대조는 독립적인 인용·회계 정확도 평가나 정확도 95% 달성 실적을 뜻하지 않습니다.

## 수집·저장 범위

- 요청: 허용된 `data.sec.gov` JSON과 `www.sec.gov/Archives/edgar/data/` HTML만 사용합니다. 응답 주소가 요청한 공시와 달라도 차단합니다.
- 같은 SQLite 캐시를 사용하는 프로세스 전체에서 초당 최대 2회, 재무 수집 도구 1회에서 HTTP 요청 최대 24회. 원문 HTML과 수정본 확인에 필요한 요청도 포함합니다. 이는 Agent의 논리적 도구 12회 한도와 별개의 전송 제한입니다. 단독 검산 수집 루프는 180초에 중단하며, 이미 진행 중인 소켓 읽기는 최대 15초가 추가될 수 있습니다. Agent 모드에서는 상위 프로세스가 요청 전체를 180초에 종료합니다. 일시적 오류는 최대 2회 재시도합니다.
- SQLite 캐시에 원 응답·SHA-256·수집 시각을 저장합니다. 같은 URL의 이전 스냅샷도 보존합니다.
- 24시간 이내 캐시를 재사용합니다. 실패 시 오래된 캐시를 사용하면 보고서에 사유와 수집 시각을 표시합니다.
- 일부 기업 조회가 실패해도 나머지 결과와 보류 사유를 반환합니다. CLI는 자료가 하나도 없으면 종료 코드 2를 반환합니다.
- 현재는 하나의 호스트/캐시를 사용하는 실행 환경입니다. 여러 프로세스는 요청 슬롯과 비용 장부를 공유합니다. 독립된 여러 서버의 요청·비용 제한 통합은 지원하지 않으므로 배포는 단일 인스턴스로 제한합니다.

캐시는 **현재 수집한 자료를 제출일로 필터링**한 것입니다. SEC가 나중에 정정·삭제한 사실까지 복원하는 당시 원본 아카이브는 아닙니다. 과거 시점의 완전한 재현에는 당시 보존한 스냅샷이 필요합니다.

## 2026-10-12 평가·재현 상태

- 1차 심사 전 작업은 실행 화면 디자인과 오류 점검입니다. 청록색·회색 테마, 입력 영역, 비교 요약/원문 근거/실행 기록 탭, 저장 버튼과 모바일 배치를 정리했습니다. 추가 기능·후속 평가·공개 배포는 1차 심사 합격 확인 후 진행합니다.
- 화면 오류 점검에서 공백 질의가 분석을 시작하는 문제와 손상된 SQLite 저장소가 화면을 중단하는 문제를 재현·수정했습니다. 입력 누락과 저장소 오류를 한국어로 안내하며, 손상 파일을 자동 삭제하거나 비용 장부를 초기화하지 않습니다. API 오류 안내는 모의 응답으로 검사했습니다.

- 두 연차기간 모두 증가율을 계산하며, 같은 공시의 전기 매출을 사용합니다. 실제 세 기업 24개 지표의 원문 대조·계산 규칙이 통과했습니다. 브라우저에서도 이전 연도의 AMD 13.69%, Intel -2.08% 표시를 확인했습니다.
- 오프라인 자동 검사 **114개 통과**. 원문 동결 읽기 전용, 여러 프로세스 SEC 요청 슬롯, 두 연차 증가율과 평가 분모 반례, 화면 오류와 복구, ‘제3자’ 표현 및 수치·인용 차단 반례를 포함합니다. 이전 77·89·98·102개 기록은 당시 단계의 이력입니다.
- [원문 기반 정답 60문항 및 프로토콜](evaluation/README.md), [동결 결과·실패 분석](docs/evaluation-results.md), [집계 JSON](evaluation/results-v1.json). 동결 120회 중 80회 완료·40회 API 429 실패를 보존했습니다. 당시 진단은 API 잔액 소진을 반환했습니다. 아래 연결 복구 점검을 기존 평가와 합산하지 않습니다. **Agent 우위·전체 품질 목표 달성을 주장하지 않습니다.**
- Windows 실행 외에 Python 3.12.15 Linux Docker에서 빌드·가상 예제·건강 상태와 재시작 후 비용 장부 보존을 확인했습니다. [실행/배포 안내](docs/deployment.md)를 따르세요. 공개 데모 URL은 아직 없습니다.
- [사용자 검토시간 실험 절차](docs/user-study.md), [데이터·모델·라이선스 및 AI 활용 내역](docs/resources.md). 외부 전문가 검수와 30% 시간 단축은 미측정입니다.
- 사용자 요청으로 유료 API 작동 점검을 재개했습니다. 최소 연결 1회와 Windows 화면의 두 분석에서 총 LLM 9회, 추가 예산 환산 11.809875원, 미확정 0회였습니다. 두 기업의 공급망 위험 설명·인용은 생성됐으나, 세 기업 기본 질문은 인용 오류와 ‘제3자’ 숫자 오탐으로 설명을 보류했습니다. [두 실행의 기록과 한계](docs/demos.md#유료-api-작동-재점검)를 함께 확인하세요. 전체 재평가·공개 배포는 아직 수행하지 않았습니다.
- 후속 디버깅에서 ‘제3자’와 흔한 조사 형태의 숫자 오탐을 수정했습니다. 실제 수치·비율·금액 및 잘못된 인용은 계속 차단합니다. 저장된 실패 후보의 오프라인 재생과 별도 실제 API 분석에서 각각 설명 3개를 확인했습니다. 새 API 분석은 3회·3.931675원으로 완료됐으며 [실행 범위와 한계](docs/demos.md#숫자-오탐-수정과-후속-확인)를 기록했습니다. v1 기록은 당시 코드와 함께 보존하며, [보존본의 재현 절차](evaluation/README.md#오류-수정-이후-v1-재현)를 따릅니다.

[제출 자료 목록과 남은 확인](docs/submission-checklist.md)을 참고하세요. 공식 양식 예선 10쪽 PDF·본선 10쪽 발표 PDF·대본/Q&A·90초 저장 결과 해설 영상은 로컬 결과물 폴더에 있습니다. 공개 배포·영상 업로드·최종 제출은 하지 않았습니다.

## 개발과 검증

```powershell
uv run pytest
```

검산, 기준일, 수정본 선택, 누락·충돌·비정상 값, HTTP 오류·캐시·주소 제한, 보고서 내보내기, Streamlit 사용자 흐름을 검사합니다. 테스트는 합성 입력과 HTTP 모의 응답을 사용하며 라이브 API 성공이나 독립적인 금융 정확도를 입증하지 않습니다.

```text
app.py                       Streamlit 입력·비교표·근거·다운로드
ui/styles.css                실행 화면의 색상·간격·반응형 스타일
src/proofresearch/
  models.py                  입력과 결과 스키마
  sec.py                     SEC 조회·제한·SQLite 스냅샷
  analysis.py                공시 선택·계정 추출·Decimal 검산
  source.py                  원문 표 대조·근거 위치·검토된 수정 범위
  amendments.json            해시로 고정한 수정본 검토 기록
  workflow.py                수집 → 검증 → 비교 → 결과 상태 흐름
  agent.py                   제한된 도구 선택·재탐색·프로세스 종료
  llm.py                     API 호출·횟수 제한·SQLite 비용 예약
  retrieval.py               기업·공시 범위의 원문 문단 검색
  report.py                  HTML·CSV·근거·실행 이력
  cli.py                     명령행 실행
  sample.json                명시적으로 분리된 합성 예제
tests/                       오프라인 회귀 검사
docs/implementation-plan.md   기획안 요구사항과 후속 작업
```

기존 공모전 PPTX·PDF·기획안 원본과 `.build`는 로컬에 보존하며 이 공개 코드 저장소에 포함하지 않습니다. 서비스는 리서치 보조 목적이며 매매 주문·가격 예측·목표주가 산출 기능을 제공하지 않습니다.
