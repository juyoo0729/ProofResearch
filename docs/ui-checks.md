# 실행 화면 점검 기록

2026-10-13 Windows의 Codex 내장 브라우저에서 `1b95db045173889b5586fe72b6d551c96c4a2356`의 Streamlit 화면을 확인했다. 이번 검사는 로컬 화면 검사이며, [별도의 클라우드 실행 결과](cloud-development.md)와 구분한다. 임시 서버에 API 키·SEC 연락처를 전달하지 않고 합성 예제로만 실행했다.

## 확인한 흐름

| 항목 | 확인 결과 |
| --- | --- |
| 데스크톱 1280×720 | 제목·비교 조건·실행 버튼 배치 확인 |
| 휴대폰 폭 390×844 | 기업·기준일 입력이 세로로 배치되고 결과 탭과 다운로드 버튼에 접근 가능 |
| 좁은 폭 320×800 | 실행 기록의 긴 값이 줄바꿈되며 페이지 전체 가로 넘침 없음 |
| 합성 A·B, 기준일 2026-03-01 | 비교 PASS 표시, 비교표를 가로 스크롤해 네 지표 확인 |
| 공백·줄바꿈·탭만 있는 질의 | 한국어 입력 오류 안내, 이전 보고서와 다운로드 버튼 제거 |
| 오류 후 질의 수정·A·C 실행 | 정상 복구, 결산기간 차이로 비교 HOLD 표시 |

| 브라우저 오류·경고 | 이번 탭에서 수집된 오류·경고 없음 |

390px와 320px에서 문서·본문 너비는 각각 화면 너비와 같았다. 비교표는 별도 가로 스크롤을 사용하며, 가상 기업의 근거에 실제 SEC 링크를 붙이지 않는다.

## 실제 다운로드 대조

A·B 보고서의 HTML·CSV·근거 JSON을 화면 버튼으로 각각 내려받고 파일 내용을 검사했다. 실행 ID는 `b69942edf2804174a77a193bdc2a7887`이다.

- CSV의 16개 지표 행을 JSON의 기업·보고기간·지표별 값·단위·판정과 대조해 모두 일치했다.
- 2025년 합성 A의 매출 125,000,000 USD·영업이익률 20%, B의 매출 88,000,000 USD·영업이익률 12.5%가 내보내기에서 일치했다.
- HTML의 가상 자료 표시, CSV·JSON의 sample 모드·기준일·기업 범위, UTF-8 읽기와 실제 SEC 링크가 없음을 확인했다.

파일과 화면 캡처는 로컬에 보관하고 Git에는 이 검사 기록만 반영한다.

## 범위와 남은 확인

이번 흐름에서 재현된 앱 오류가 없어 앱 코드와 의존성은 변경하지 않았다. 코드 변경이 없는 시각·다운로드 검사이므로 전체 자동 검사는 반복하지 않았다. 클라우드에서 통과한 114개 검사는 해당 문서의 별도 실행 결과다.

브라우저 화면 크기를 조절한 검사이며 실제 휴대폰·터치·Safari 및 클라우드 브라우저 검증은 아니다. 유료 API·실제 SEC·전체 재평가·공개 배포는 실행하지 않았다. 예선 제출본과 동결 평가 기록은 변경하지 않았다. 이 결과는 독립적인 정확도 또는 외부 사용성 평가가 아니다.

## 저장 HTML의 긴 실행 기록 표시 수정

2026-10-13 `e51b757`에서 내보낸 HTML에 긴 종료 사유가 있으면 `<pre>`의 줄바꿈이 없어 보고서 전체가 옆으로 넘치는 문제를 재현했다. 합성 A·B 보고서에 표시 확인용 실행 기록을 넣었으며 실제 AI를 호출한 결과가 아니다. 390px 브라우저에서 본문 너비는 1,049px, 실행 기록 영역의 내용 너비는 1,029px였다.

실행 기록의 공백·들여쓰기를 유지하면서 줄바꿈하도록 HTML의 CSS만 수정했다. 같은 보고서 본문의 모든 텍스트와 근거 링크를 수정 전후 대조하여 동일함을 확인했다.

| 브라우저 폭 | 수정 후 문서/가용 폭 | 실행 기록 내용/영역 폭 | 결과 |
| --- | --- | --- | --- |
| 320px | 305 / 305px | 265 / 265px | 전체 가로 넘침 없음 |
| 390px | 375 / 375px | 335 / 335px | 전체 가로 넘침 없음 |
| 1280px | 1265 / 1265px | 1048 / 1048px | 전체 가로 넘침 없음 |

가용 폭은 세로 스크롤바 15px를 제외한 너비다. 모바일 비교표는 자체 가로 스크롤을 유지한다. 320px에서 합성 A의 20.00% 링크를 눌러 해당 영업이익률의 근거·계산식으로 이동하는 것도 확인했다. 기존 내보내기·화면 검사 `uv run pytest tests/test_report_and_app.py`는 8개 통과(3.20초)했다. 표시 규칙을 그대로 복사한 자동 검사는 추가하지 않았다.

합성 입력, 수정 전후 HTML과 화면 캡처는 Git에서 제외된 `work/export-layout-check/`에 보존한다. 기존 클라우드 121개 검사는 이 CSS 수정 전 코드의 기록이며, 이번 확인은 Windows 내장 브라우저에서 수행했다. 실제 휴대폰·외부 사용자·클라우드 브라우저 검증이나 독립 정확도 평가를 뜻하지 않는다.
