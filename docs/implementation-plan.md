# 기획안에서 구현으로

기준일 2026-10-12. 기존 공식 양식 기획안과 Python·Pydantic·Streamlit·SQLite 구조를 유지한다. 구현·연결·내부 평가·외부 검수·최종 제출은 각각 구별한다.

사용자 결정에 따라 1차 심사 전에는 실행 화면 디자인을 개선하고 오류를 점검한다. 색상·글자·입력 영역·결과 탭·모바일 배치를 정리하고, 공백 입력과 저장소 오류의 화면 처리를 보완했다. 후속 디버깅으로 Agent의 ‘제3자’ 숫자 오탐도 수정했다. 검산·검색·동결 평가 절차는 유지한다. 추가 기능·후속 전체 평가·공개 배포는 1차 심사 합격 확인 후 재개한다.

2026-10-12 추가 요청에 따라 유료 API 작동 점검은 수행했다. 연결 복구와 Windows 화면의 두 분석을 확인했으며, 기존 동결 120회 평가와 합산하지 않았다. 기본 질문의 설명 보류와 ‘제3자’ 숫자 오탐 및 후속 수정 검증을 [실행 기록](demos.md#유료-api-작동-재점검)에 남겼다. v1은 당시 코드와 원문·응답 보존본에서 재현한다.

예선 기획안 v4(PDF·PPTX·본문)는 API 복구, 오탐 수정 후 실제 세 기업 분석과 자동 검사 114개를 반영했다. 10쪽 양식·한글·표·출처 링크·키와 SEC 연락처 제외를 확인하고 기존 v1~v3는 보존했다. 평가표의 80회 완료·40회 오류는 바꾸지 않았다. 공식 일정·배점은 재확인했으며, 최소 투표 횟수는 여전히 구체적인 공지가 필요하다.

## 현재 평가의 해석

Agent 수치 정답은 응답된 12문항에서 12개다. 그러나 전체 24개 대비 응답률은 50%, 인용 타당 문항은 14/32, 보류는 6/8이다. 18개 Agent 실행은 API 잔액 오류로 실패했다. 단일 요약·RAG도 각각 12·10개 실패했으므로 정상 응답만 골라 우위를 주장하지 않는다. 서술 인용 두 건의 추가 주장·한정 누락과 RAG 계산 한 건의 반올림 오류를 기록했다. 자세한 분모와 제한은 [평가 결과](evaluation-results.md)를 따른다.

## 다음 작업

아래 후속 작업은 **1차 심사 합격 확인 이후**의 목록이다. 충전 안내만으로 배포나 후속 평가를 자동 재개하지 않는다.

1. 유료 API 연결 복구와 ‘제3자’ 오탐 수정은 확인했다. v1 기록을 보존한 별도 전체 평가를 계획하고, 남은 설명 보류·의미 인용 사례를 검증한다. 성공 사례와 재시도 성공만 합쳐 평가하지 않는다.
2. 본선 검토안·대본·영상을 별도 전체 평가와 외부 검토 결과에 맞춰 갱신한다. 예선 v4에 반영한 단일 작동 점검을 새 평가 성적으로 사용하지 않는다. 품질 목표 미달은 공개한다.
3. 담당자의 원문 확인·수정까지 포함한 [사용자 검토시간 과제](user-study.md)를 수행할 때만 30% 단축 여부를 판단한다.
4. 준비된 [Docker 실행 환경](deployment.md)의 공개 대상·호스팅·비용·비밀 설정을 확정하고 공개 배포 승인을 받는다. 실행 URL을 얻은 뒤 실제 외부 환경에서 세 흐름을 점검한다.
5. 공식 일정·접수 명칭·AI 활용 표기를 최종 확인하고 예선/본선 제출을 구분해 처리한다. 참가자 상호 투표는 사용자가 직접 수행한다.

## 설계 선택과 검증 경계

- 재무 수치와 비율은 코드가 계산한다. 자유형 질문의 모든 의도를 UI가 자동 추출하는 제품은 아니며 평가는 구조화 보고서에서 대상 기간·지표를 추출한다.
- 두 연차 모두 해당 공시의 비교 매출을 쓴다. 다른 공시의 값으로 누락을 조용히 메우지 않는다.
- 매출 계정·기간·통화 일치는 기업 사업구조의 동질성을 의미하지 않는다. 부문·사용자 정의 계정·비GAAP·환산은 제외한다.
- Agent 전체를 별도 프로세스로 실행하고 180초에 종료한다. 자동 검사는 시간을 축소한 멈춤 작업으로 검증했으며 실 배포의 180초 대기 시험은 별도다.
- 자동 검사 114개는 회귀 방지 증거다. 공백 입력 차단, 손상된 캐시·비용 장부의 오류 안내, 기업·날짜 누락, 모드 전환과 실패 후 복구, ‘제3자’ 표현의 허용과 실제 수치·잘못된 인용 차단을 포함한다. 자동 검사의 API 오류는 모의이며, 위 실제 유료 작동 점검과 구분한다. 원문 표 대조, 독립 정확도, 외부 사용자 시간 절감과 같은 성과로 바꾸어 표현하지 않는다.
- 초기 77·89개 검사와 21개 지표 시연은 당시 버전의 기록이다. 현재 두 연차 지표는 24개이며 예전 보고서를 최신 실행인 것처럼 표시하지 않는다.
- 정답·평가 코드·원문 스냅샷의 동결 해시는 보존한다. 잔액 오류를 고치기 위해 v1 정답이나 채점기를 바꾸지 않는다.
