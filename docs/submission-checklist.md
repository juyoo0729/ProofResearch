현재 작업 범위는 실행 화면 디자인이다. 추가 개발·후속 실험·서버 구매·공개 배포는 사용자 결정에 따라 1차 심사 합격 확인 이후로 보류한다. 아래 배포 항목은 본선 준비 목록이며 지금 수행할 작업이 아니다.

예선 v1·v2와 본선 v1은 보존된 이전 초안이다. 위 표의 파일을 현재 검토 대상으로 사용한다. 영상은 실시간 실행 녹화가 아니며, 로그 당시 21개 지표와 현재 24개 지표를 구분한다.

## 제출 전에 해결할 항목

1. API 잔액 복구 뒤 별도 전체 평가를 수행한다. v1의 80회 완료·40회 오류와 의미 인용 실패 두 건을 지우지 않는다. 현재 결과는 방법 간 우위나 품질 목표 달성의 증거가 아니다.
2. 참가자가 접수 명칭·개인 참가 정보·AI 활용 내역을 확인한다. 사용자 검토시간 30% 단축은 아직 미측정이다.
3. 본선 공개 데모의 대상·호스팅·별도 운영비·비밀 설정을 확정하고 배포 승인을 받는다. 단일 런타임과 영속 비용 장부를 유지하며 실제 외부 URL에서 세 흐름을 점검한다.
4. 발표 전 모델 가격 기록을 재검토한다. 현재 코드의 30일 가격 유효기간은 예선 마감 전에 만료되므로, 확인 없이 날짜만 연장하지 않는다.
5. 공식 일정·양식 변경을 다시 확인한다. 예선 11월12일 10시, 상호 평가 11월12일 12시~19일 10시, 본선 12월22일 10시(KST)다. 최소 투표 횟수는 현재 공식 안내에 없어 추후 확인한다. 투표는 참가자가 직접 수행한다.
6. 공개 업로드·영상 게시·최종 접수는 별도 실제 수행 단계다. 파일 준비를 제출 완료라고 표현하지 않는다.

공식 근거와 평가 항목 매핑은 [contest-evidence.md](contest-evidence.md), 환경은 [deployment.md](deployment.md), 실험 한계는 [evaluation-results.md](evaluation-results.md)에 있다.
