# 평가 항목과 제출 근거

배점은 사용자가 지정한 공모전 평가 기준이다. [공식 대회 안내](https://daker.ai/public/hackathons/kic-ai-agent-competition)의 일정·제출 형식은 2026-10-11에 확인했으며, 제출 직전에 변경 공지와 평가 탭을 다시 확인해야 한다. 구현 동작과 독립 성능 평가는 구분한다.

## 예선 전문가 평가

| 항목 | 배점 | 현재 근거 | 남은 작업 |
| --- | ---: | --- | --- |
| 문제 정의·주제 적합성 | 20 | README: 공시 재확인 업무, 기간/계정 비교 제약 | 담당자의 실제 검토·수정 시간 측정 |
| Agent 구성·설계 | 25 | agent.py, 도구 계획·선택·재탐색·종료 로그 | 동결 질의에서 재탐색 효과 평가 |
| 차별성·창의성 | 20 | 원문 표/문단 위치, 계산 근거, 조건 불일치 보류 | 단일 요약/RAG와 동일 조건 비교 |
| 실현 가능성 | 20 | 실제 SEC·GPT 실행, 비용 예약, 잠금 파일·실행 안내 | 다른 환경 재현·공개 데모 |
| 활용성·확장성 | 15 | 기업/기준일/질의 입력, HTML·CSV·실행 기록 | 실제 사용자 검토와 업무 효용 확인 |

## 제출 체크리스트

- 예선: **2026-11-12 10:00 KST**, 공식 양식 **10쪽 이내 PDF**. 기존 기획안을 현재 증거와 미측정 항목으로 갱신한 뒤 렌더링·페이지 수를 검사한다.
- 예선 점수: 전문가 70%·상호 평가 30%. 상호 평가 **11-12 12:00 ~ 11-19 10:00 KST**. 최소 투표의 구체적인 개수는 **미확인**이며 공식 평가 화면·공지에서 확인한다. 참가자가 직접 투표한다.
- 본선: **2026-12-22 10:00 KST**, 실행 가능한 데모 URL·GitHub 코드/가이드·발표 PDF. 시연영상은 선택 가산점 항목으로 준비한다. 발표 10분·질의응답 10분.
- 비공개 키와 연락처, 요청당/전체 예산, 여러 프로세스의 SEC 접근 제한을 배포 환경에서 확인한다. 공개·최종 제출은 사용자 허용 범위 안에서 수행한다.
- 현재 상태는 **개발 및 제출 준비 중**이다. 코드·테스트 통과, 파일 작성, 준비 완료, 최종 제출 완료를 서로 바꾸어 표현하지 않는다.

## 성과로 주장할 수 없는 항목

개발 20/동결 40 정답셋, 수치 정확도 95%·유효 응답률 80%·인용 타당성 95%·보류 8/8, 기준선 대비 우위, 검토시간 30% 단축은 아직 측정하지 않았다. 테스트 개수와 API 연결은 이 성과의 증거가 아니다.
